# Resumos de Pull Requests da Web

Esta pasta manterá o histórico das descrições usadas nos pull requests relacionados ao frontend.

## Convenção

- Nome: `NNN-descricao-curta.md`.
- Numeração sequencial com três dígitos.
- Conteúdo em português.
- O arquivo deve refletir a descrição final publicada no GitHub.
- Alterações posteriores ao PR devem ser atualizadas no mesmo resumo antes do merge.
