# Resumos de Pull Requests

Esta pasta mantém o histórico das descrições usadas nos pull requests do projeto.

## Convenção

- Nome: `NNN-descricao-curta.md`.
- Numeração sequencial com três dígitos.
- Conteúdo em português.
- O arquivo deve refletir a descrição final publicada no GitHub.
- Alterações posteriores ao PR devem ser atualizadas no mesmo resumo antes do merge.

- [`005-dashboard-management-polish.md`](005-dashboard-management-polish.md) - Ajustes de gestão do dashboard, inativos, RG e ações por ícone.
